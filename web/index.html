Setup path

From server to phone

01

Install on the machine with tmux

The install command downloads the latest server CLI from GitHub Releases into ~/.telemux and checks the SHA-256.

02

Run it on your private network

On systemd hosts, the installer starts a user telemux service on 0.0.0.0:14441. Do not expose a no-auth server publicly.

03

Connect from the app

Use the server Tailscale IP as the host and keep the port at 14441 unless you changed it.

Keep it running

systemd service

The server CLI is a single Node 24 executable. The installer writes a user systemd service when available, then restarts it after future installer runs so config changes take effect.

systemctl --user status telemux
journalctl --user -u telemux -f
